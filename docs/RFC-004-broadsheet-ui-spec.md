# RFC-004: 中文百年大报视觉排版与前端界面规范

**状态**：已确认，准备实施（v0.4）  
**日期**：2026-09-25  
**前置**：RFC-002（Notes 基础信息架构与卡片解剖学）、RFC-003（跨端协同系统架构与笔记全生命周期设计）  
**定位**：定义《AI 讨论纪事报》在 Web 桌面端与手机移动端的前端界面视觉语言、组件解剖学与交互规范。后续代码落地必须严格消费本文定义的 Token 与版面结构。

## 1. 设计哲学与核心隐喻

本系统的视觉基调为 **「中文百年大报（The Classic Broadsheet）」**，融合西方严肃大报（*The New York Times*）的严谨版芯纪律与中国典雅文人刊物（*《新视线》/《生活月刊》*）的书卷气。

### 三条核心设计原则：
1. **彻底告别“软件工具味”与卡片堆砌**：界面骨架不是“大灰底上浮动白色圆角卡片”，而是**一张通透的泛黄新闻大报（Broadsheet）**。分割依靠负空间、字阶张力与牛津双线（Oxford Rules），绝无无意义的容器套娃；
2. **高信息浓度的多问题头版层次**：一份报纸头版从来不是孤零零的一句话，而是有**主条（深度推演）、副条（概念辨析）与简讯（微言速测）**构成的丰富版面；
3. **母语优先与中文字阶张力**：选用典雅的**思源宋体（Noto Serif SC）**，横细竖粗、墨韵沉稳，搭配首字下沉与 1.8 舒适行高，带来纯正的母语阅读沉浸感。

手机端是碎片时间进行记忆唤醒的专属载体，其核心版面为 **《AI 讨论纪事报》头版号外**。

### 2.1 手机端组件解剖清单

| 栏目 / 组件 | 视觉角色 | 交互行为 | 排版特征 |
|---|---|---|---|
| **报头与报眼** | 报刊权威感与刊期锚定 | 静态展示 | 顶部小字元信息 + 24px 加粗宋体报头 + 牛津双线 |
| **头版头条 (q1)** | 主回忆目标（长逻辑推演） | 点击展开思考线索；点击撕折展开号外原文 | 16px-18px Black 宋体标题 + 斜体副题 + 首字下沉原笔记 |
| **报眼要闻 (q2)** | 次回忆目标（概念辨析） | 点击轻量展开辨析要点 | 14px 加粗宋体 + 独立解析抽屉 |
| **微言速测 (q3)** | 快速自测（直觉核对） | 点击即时揭晓答案 | 12px 紧凑宋体 + 单行答案卡 |
| **随笔批注栏** | 思考沉淀（Thought） | 键盘输入随感，点「沉淀」即刻写回云端 | 质朴单线输入框 + 墨黑按钮 + 成功提示 |
| **底栏换版按钮** | 漫游流转（换一批） | 点击触发整体报纸重新排版 | 沉稳暗红背景 (#A31D1D) + 白色宋体字 |

## 3. Web 桌面端界面解剖学 (Desktop Multi-Column Broadsheet)

Web 桌面端服务于在电脑前深度阅读、整理与检索笔记，采用 **经典多栏大报版芯**（左栏专栏目次 4 列，中栏头条长文 8 列，内置检索与批注流）：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 顶栏: 报刊标题 // 档案库                [DEEPSEEK: 同步正常]  [系统设置]│
├────────────────────────────────────────────────────────────────────────┤
│                           AI 讨论纪事报                                │
│                   “记录人与大模型碰撞之洞见，于闲暇处重温以明心智”      │
│ ══════════════════════════════════════════════════════════════════════ │
│ 专栏目次 (4 列)           │ 头版头条深度阅览区 (8 列)                  │
│ ------------------------- │ ------------------------------------------ │
│ // 专栏会话目次 (14 篇)   │ [头条要闻深度存录]                         │
│                           │ 论六层架构中持久化模型映射为何不可外泄？   │
│ ▪ 专栏 01 · CHATGPT       │ 记录于 ChatGPT · 昨天 16:10                │
│   Python 六层架构学习     │                                            │
│   3 篇笔记 · 领域防腐隔离 │ 在六层架构中，数据持久化适配器通过实现领域 │
│                           │ 层声明的 Repository 端口，来承担 ORM 到    │
│ ▪ 专栏 02 · KIMI          │ Domain Model 的双向解包与装包过程...       │
│   分布式 Raft 共识协议    │ (首字下沉排版，两端对齐，大报质感)         │
│   4 篇笔记 · 随机超时选举 │                                            │
│                           │ ┌────────────────────────────────────────┐ │
│ // DEEPSEEK 认知雷达      │ │ // DEEPSEEK 记忆锚点:                  │ │
│ 模型自演进画像：近期关注点│ │ 核心业务规则如磐石，数据库与外设皆流沙 │ │
│ 正从单体框架向分布式迁移  │ └────────────────────────────────────────┘ │
│                           │ 【用户随笔批注】当时讨论重点在防腐层隔离... │
└───────────────────────────┴────────────────────────────────────────────┘
```

### 3.1 Web 端三区域核心职能：
1. **左栏（会话专栏目次）**：
   - 自动聚合同一会话的所有笔记条目；
   - 常驻显示 DeepSeek 异步画像 Agent 自动提取的「认知雷达摘要」；
   - 点击任一专栏，中栏即刻无刷新平滑载入该会话的头版长文。
2. **中栏（头条深度阅读区）**：
   - 24px 思源宋体头条标题；
   - 严谨的西文+中文混排规则（中西文之间保留 0.25 空格呼吸感）；
   - 正文段落启用首字下沉（Drop Cap），排版两端对齐（Justified）；
   - 嵌入 DeepSeek 记忆锚点墨黑印记与代码块。
3. **右栏/内嵌交互区（检索与批注流）**：
   - 吸顶式 ⌘K 全文检索输入框，实时过滤专栏目次与笔记正文；
   - 历史 Thoughts 随想流展示；
   - 提供云端同步设置弹窗（配置 DeepSeek API Key、Base URL 与 Model）。

## 4. 设计规范标尺与 Token 清单 (Design Tokens)

后续无论是 Web 扩展页面（CSS），还是手机端 React Native 样式表，均需严格映射以下变量体系：

### 4.1 报刊油墨调色盘 (Color Palette)

```css
:root {
  /* 纸张表面 */
  --newsprint-bg: #f8f6f0;         /* 经典微黄新闻纸底色 */
  --newsprint-white: #ffffff;      /* 头版内页与卡片纯白 */
  --newsprint-dim: #ece7db;        /* 报头、边栏与折页暗部 */

  /* 墨水层次 */
  --ink-black: #1a1918;            /* 铅印浓黑主文字 (对比度 > 12:1) */
  --ink-muted: #5e5a52;            /* 次级引言、副题、元信息 */
  --ink-faint: #8c867a;            /* 辅助说明、占位符 */

  /* 经典报刊强调色 */
  --crimson-red: #a31d1d;          /* 传统大报暗红（报眼、重点标识、换版按钮）*/
  --crimson-hover: #831414;        /* 暗红悬停态 */

  /* 线条与分隔 */
  --oxford-line: #1a1918;          /* 牛津双线主色 */
  --border-subtle: #d8d2c2;        /* 内页纤细分隔线 */
}
```

### 4.2 排版张力规范 (Typography Hierarchy)

```css
/* 字体族定义 */
--font-serif-masthead: 'DM Serif Display', 'Noto Serif SC', serif;
--font-serif-body: 'Noto Serif SC', 'Newsreader', Georgia, serif;
--font-mono-meta: 'JetBrains Mono', Menlo, monospace;

/* 字阶梯 (Type Scale) */
--text-masthead: 42px - 48px / 1.0;   /* 大报头 */
--text-lead-title: 22px - 26px / 1.25;/* 头条大标题 (Black 900) */
--text-sub-title: 13px - 14px / 1.5;  /* 栏目副标题 / 辨析题标题 */
--text-body: 13px / 1.8;              /* 正文铅字排版 (行高 1.8 确保中文呼吸感) */
--text-meta: 9px - 10px / 1.4;        /* 报眼、刊期、状态等元信息 */
```

### 4.3 版芯与几何准则 (Geometry & Rules)

1. **牛津双线 (Oxford Rule)**：
   - 1px 细线 + 2.5px 粗线组合，构筑古典报刊的权威分割线；
2. **直角纪律 (Strict Zero Border-Radius)**：
   - 彻底废除 16px/24px 玩具感大圆角，所有版面、按钮、输入框严格采用 **`0px` 直角** 或轻微 **`2px` 工业倒角**；
3. **首字下沉 (Drop Cap)**：
   - 正文首字尺寸为正文的 3.2 倍，占据 2~3 行文本高度，采用暗红色加粗呈现；
4. **纸张物理撕折微动效**：
   - 展开号外时采用轻微的物理下沉位移动态（`translate-y` 与渐变折痕阴影），模拟拉开折页的阻尼感。

## 5. 交互状态机规范 (Interaction State Machine)

手机端头版号外遵循严密的防剧透状态流转：

```stateDiagram-v2
    [*] --> Folded: 打开手机，印制号外头版
    
    state Folded {
        [*] --> ClueHidden: 默认隐藏线索
        ClueHidden --> ClueVisible: 点击[研读思考线索]
        ClueVisible --> ClueHidden: 点击[隐去思考线索]
    }

    Folded --> Unfolded: 点击[翻阅号外原文对照]
    
    state Unfolded {
        [*] --> NoteInspection: 阅览首字下沉原笔记与锚点
        NoteInspection --> ThoughtCommitted: 输入随感并点击[沉淀]
    }

    Unfolded --> Folded: 点击[收拢号外原文]
    
    Folded --> Folded: 点击[印制下一版号外] (重新抽样会话并刷新三题)
    Unfolded --> Folded: 点击[印制下一版号外]
```
